========================================================================
             ImmBiz Books - Quick Windows User Guide
========================================================================

Welcome to ImmBiz Books! Everything has been configured to run locally
and completely offline on this computer with NO technical setup needed.

------------------------------------------------------------------------
HOW TO START THE APP (1 STEP):
------------------------------------------------------------------------
Double-click on:

    Run_ImmBiz_Books.bat

That's it!
- The app will automatically configure the environment.
- The embedded database (immbiz.db) is already included with all data.
- Both the Frontend and Backend start automatically on http://localhost:8000.
- Your web browser (Edge/Chrome) will pop open automatically to the login page!
